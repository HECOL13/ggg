# Avtobys QR — история автобусов

Мобильное веб-приложение для билета Avtobys. Экран билета оформлен по образцу `мама.html`, механика и история маршрутов взяты из `index.html`.

## Установка на Samsung Galaxy S24 FE

Это устанавливаемое веб-приложение (PWA), а не APK-файл. Android добавит его на телефон через системное окно установки Chrome.

1. Размести содержимое этой папки на HTTPS-хостинге (например, GitHub Pages или Netlify). Камера и установка не работают при открытии `index.html` как локального файла.
2. На телефоне открой получившийся HTTPS-адрес в Google Chrome.
3. Открой **Настройки** → нажми **Установить приложение** и подтверди установку. Если Chrome не показывает системное окно, нажми `⋮` → **Установить приложение** или **Добавить на главный экран**.
4. После установки запускай Avtobys QR с иконки на главном экране.

Кнопка установки открывает системный запрос только после нажатия. В браузере без такого запроса она показывает инструкцию по установке через меню браузера.

## Возможности

- Ручной ввод кода автобуса и времени билета.
- Распознавание кода камерой.
- История маршрутов и кодов хранится на этом устройстве.
- Масштаб QR-кода.
- Кэширование оболочки приложения для повторного открытия без сети. Распознавание текста использует внешнюю библиотеку и требует подключения к интернету при первом запуске сканера.

Для выпуска новой версии увеличь значение `CACHE_NAME` в `sw.js`.
